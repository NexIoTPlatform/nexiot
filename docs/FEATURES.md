# NexIoT 开源版与企业版功能对比

**先看版本差异，再按业务领域查看完整能力。**

[返回项目首页](../README.md) · [版本总览](#overview) · [详细功能](#details) · [视频能力](#video) · [商业版本选择](#commercial-editions)

</div>

---

**开源版**提供 MQTT / HTTP 设备应用的通用平台基础。**企业版及商业扩展**面向更多设备协议、工业采集、视频、AIoT、规则和可视化业务。

本表以当前开源仓库、企业版代码和商业版本介绍整理。商业代码具备的能力与购买套餐包含的模块分别说明，具体交付范围见[商业版本选择](#commercial-editions)。

## 标记说明

| 标记 | 含义 |
| --- | --- |
| **✅ 包含** | 当前版本提供该项基础功能。 |
| **— 未包含** | 本开源仓库未提供对应业务模块或使用入口。 |
| **🔌 协议插件** | 商业协议插件，按商业版本及协议清单交付。 |
| **➕ 商业扩展** | 企业代码已有扩展能力，所购套餐是否包含需确认。 |
| **🧩 专项选配** | 源码、适配或服务按专项范围提供。 |
| **⚙️ 配置启用** | 实现保留，使用前需配置依赖并验证运行环境。 |

“包含”表示功能范围，不代表所有厂家、固件、部署方式和设备规模都具有相同支持程度。

## 三、商业版本如何选择

下表参考[商业版本介绍](https://docs.nexiot.cc/versions/plugins)，仅说明版本定位；价格、更新期限、支持服务和最终授权范围以当前确认的方案为准。

| 版本 | 适合场景 | 主要范围 |
| --- | --- | --- |
| **开源版** | 学习、自主开发和基于开放能力建设应用 | 本仓库已有功能，MQTT / HTTP 及通用设备平台。 |
| **基础版** | 自研团队与基础设备项目交付 | 平台基础基线、MQTT / HTTP、配套小程序与 H5；其他协议可选配。 |
| **企业版（集群）** | 多协议接入与多节点项目 | 基础版范围、商业产品页协议清单及集群方案；不等同于全部专项模块。 |
| **旗舰版** | 平台到应用的整体方案 | 产品页列明的企业版、应用工坊及其选配模块范围。 |

### 标准协议、专项选配与扩展确认

| 分类 | 本表对应内容 | 使用说明 |
| --- | --- | --- |
| **商业协议插件** | TCP、UDP、CTAIoT、OneNET、TTLock、WVP、ONVIF、ISC、ICC、海康/大华 SDK、萤石/乐橙/大华云 | 基础版可按需增购，企业版及旗舰版按产品页列出的协议清单包含。 |
